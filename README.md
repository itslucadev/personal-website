# lucabecker.dev

Personal site and portfolio of Luca Becker, freelance React Native developer.
It presents the work history, side projects, client work, and skills shown on the homepage, and hosts the legal pages for the apps.

Built with Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, Radix UI primitives, and Framer Motion.
Deployed on Vercel.

## Getting started

```bash
npm install
npm run dev
```

The dev server runs at http://localhost:3000.

## Scripts

| Script                 | What it does                            |
| ---------------------- | --------------------------------------- |
| `npm run dev`          | Start the Next.js dev server.           |
| `npm run build`        | Build the production bundle.            |
| `npm start`            | Serve the production build.             |
| `npm run lint`         | Check lint rules with Oxlint.           |
| `npm run lint:fix`     | Apply Oxlint's safe fixes.              |
| `npm run format`       | Format the project with Oxfmt.          |
| `npm run format:check` | Check formatting without writing files. |

Linting is Oxlint (`.oxlintrc.json`) and formatting is Oxfmt (`.oxfmtrc.json`).

## Routes

Every page lives under a locale segment, `/en` or `/de` (`src/app/[lang]`).
`src/proxy.ts` redirects unprefixed URLs such as `/` or `/agent-notch` to the visitor's locale: a saved `NEXT_LOCALE` cookie first, then the browser's `Accept-Language`, then Vercel's IP country (German for DE, AT, CH, LI), otherwise English.
Visiting a locale-prefixed page saves that locale in the cookie.

| Route                    | Contents                                                                |
| ------------------------ | ----------------------------------------------------------------------- |
| `/[lang]`                | Homepage: about, projects, client work, experience, resume download.    |
| `/[lang]/agent-notch`    | Product page for Agent Notch.                                           |
| `/[lang]/work/bv-q-club` | Lightweight visual page for the BV Q-Club e.V. client project.          |
| `/[lang]/zeiterfassung`  | Legal hub for the Zeiterfassung app, with its privacy policy and terms. |

## Translations

UI strings live in `src/i18n/dictionaries/en.ts` and `de.ts`; the German dictionary is typed against the English one, so a missing key fails the type check.
Content lists (`src/lib/work.ts`, `src/lib/stack.ts`, the experience table) carry both languages inline as `Localized` values.
Server Components read the locale and dictionary with `getLocale()` and `getDictionary()` from `src/i18n/dictionaries.ts`; Client Components use `useI18n()`.

`robots.txt` and `sitemap.xml` are generated by `src/app/robots.ts` and `src/app/sitemap.ts`.
A new indexable page has to be added to the sitemap there.

## Homepage animation timing

The entrance delays for the stacked homepage sections live in `src/lib/home-cascade.ts`.
Read that file before changing or reordering those sections; it documents which sections take part in the cascade and which still hardcode their own delays.
